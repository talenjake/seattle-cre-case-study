# Seattle Multifamily Acquisition Case Study

## Lake City Apartments | Seattle, Washington

Independent commercial real estate underwriting project analyzing the acquisition of an 8-unit Seattle multifamily property using public market information and clearly disclosed analyst assumptions.

### Investment Snapshot

| Metric | Base Case |
|---|---:|
| Purchase Price | $1,500,000 |
| Units | 8 |
| In-Place Cap Rate | 6.08% |
| Price / Unit | $187,500 |
| Year 1 NOI | $91,200 |
| Year 1 DSCR | 1.30x |
| Year 1 Cash-on-Cash Return | 3.4% |
| 5-Year Levered IRR | 10.1% |
| Equity Multiple | 1.57x |

### Underwriting Assumptions

The base case assumes 65% loan-to-value, a 6.0% interest rate, 30-year amortization, 3.0% annual rent growth, 5.0% economic vacancy, 3.0% annual expense growth, a five-year hold, and a 6.25% exit cap rate.

### Investment View

The property offers a higher in-place cap rate than the broader Seattle multifamily market benchmark used in the analysis and a lower per-unit asking basis than two recent small Seattle apartment transactions reviewed. The main weakness is modest initial levered cash yield at the assumed debt cost, so the investment thesis relies on stable occupancy, moderate NOI growth, amortization, and a disciplined exit rather than aggressive value-add assumptions.

### Skills Demonstrated

Commercial real estate underwriting, cap-rate and GRM analysis, NOI analysis, debt sizing, DSCR, levered cash flow, IRR, equity multiple, exit valuation, sensitivity analysis, transaction comparables, and Seattle market research.
